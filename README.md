# 星星 AI 英语伙伴

面向 6 到 12 岁儿童的语音优先英语学习网站。星星通过云端开放域大模型理解孩子的问题，用简短英语和温柔中文回应，并把对话自然带回朗读、单词、情景演绎和今日学习计划。

## 已实现

- 按住说话：浏览器只把语音转为文字，原始录音不上传。
- 云端开放域对话：妙搭官方 `ai-text-generate` 流式模型插件。
- AI 主导、课程约束：模型负责理解和引导，本地课程规则负责允许的任务与跳转，避免擅自跳关或泄题。
- 无麦克风演示：内置“动物单词”和“天空为什么是蓝色”两个真实云模型测试入口。
- 温柔女声：优先使用系统中文女声，页面明确显示当前声音名称。
- 七级地图、故事阅读、四类考题、奖励与成长资源。
- 移动端适配、离线课程数据和云模型失败后的安全降级。

## 云端 AI 边界

模型输入仅包含本轮语音转写文字和当前课程上下文，不要求姓名、学校、住址、电话、照片或账号。模型可回答普通开放问题，但必须回到当前学习任务；危险、自伤、成人内容或索要隐私时，提示寻找家长或老师。

课程进度、奖励和答案判定保留在本地确定性逻辑中，不能由模型直接修改。

## 本地运行

要求 Node.js 22+、npm 10+，并已登录 `lark-cli`。

```bash
npm install
npm run dev:local
```

本地地址由妙搭脚手架输出，通常为：

```text
http://localhost:8080/app/<app_id>/
```

## 验证

```bash
npm run type:check
npm run build
```

生产发布使用妙搭 `sprint/default` 分支和发布流水线。仓库不包含模型密钥、访问令牌、真实儿童数据或生产邀请码。
